## 一、角色与登录

| 角色 | role 值 | 能看到什么 |
|---|---|---|
| 普通用户 | 1 | 聊天 / 概览 / API Keys / 日志 / 钱包 / 个人资料 |
| 管理员 | 10 | 以上 + Admin 菜单（渠道/模型/用户/兑换码/订阅/系统设置） |
| 超级管理员 | 100 | 以上 +「系统信息」页 |

**登录要求**：

- 管理员账号**必须开启两步验证（2FA）**：「个人资料 → 两步验证」扫码绑定 Authenticator。操作流程见交付文档 `admin-2fa-sop.md`
- 不要在公共电脑 / 公共 Wi-Fi 下登录管理后台
- 离开工位前退出登录；定期在「个人资料 → 登录会话」检查有无陌生会话

**当前生产环境开关状态**（2026-08-17 实测 `/api/status`，改动前请再核对）：

| 开关 | 当前状态 | 影响 |
|---|---|---|
| 开放注册 | 开 | 任何人可注册 |
| 邮箱验证 / SMTP | 未配置 | 用户「忘记密码」邮件不可用 → 需管理员人工重置（见 FAQ） |
| 第三方登录（GitHub/Google/微信/Telegram 等） | 全部未开通 | 登录页只有账号密码 |
| Passkey 登录 | 关 | 用户侧不显示 |
| 签到奖励 | 关 | 用户「个人资料」不显示签到日历 |
| Turnstile 人机验证 | 关 | 注册/登录无验证码，靠限流防刷 |

## 三、渠道管理（Channels）

渠道 = 上游模型供应商的接入配置。平台把用户请求按规则路由到各渠道。

**日常操作**（2026-08-17 实测界面）：

1. **新增渠道**：「渠道」页 → 右上角「**创建渠道**」→ 选类型（OpenAI / Gemini / Claude / 自定义等）→ 填上游 Base URL、API 密钥 → 配置该渠道支持的模型列表 → 保存
2. **测试渠道**：每张渠道卡片上有**闪电图标**（测试），点击后平台用该渠道实际发一次请求，卡片显示「响应」耗时与「上次测试」时间。**新渠道上线前必测**
3. **启停渠道**：卡片上的禁用图标切换。某上游故障时先禁用，流量自动落到其他可用渠道
4. **优先级与权重**：卡片上直接显示并可编辑（实测当前渠道：优先级 0、权重 100）
5. **筛选**：支持按名称/ID/密钥、按模型、状态、类型、分组筛选；支持批量操作与标签模式
6. **模型映射**：上游模型名与平台对外模型名不一致时，在渠道内配置映射表

> 🔐 渠道密钥在数据库中 **AES-GCM 加密存储**（v1.2.10 起），页面只显示掩码。技术细节见 `docs/CHANNEL-KEY-ENCRYPTION.md`。

## 四、模型管理（Models）

Models 页维护平台对外可见的模型体系：

- **模型元数据**：模型名、描述、上下文长度、能力标签（对话/绘图/语音等）
- **模型定价**：各模型输入/输出单价（决定用户扣费）
- **分组倍率**：不同用户分组的折扣/加价倍率
- **路由可靠性**：失败重试、自动切换渠道策略
- **渠道亲和 / 模型部署**：指定某模型优先走哪些渠道

> 改价或加模型后，建议打开公开页 `https://ai.yuxin.yun/pricing` 确认对外展示已同步。

## 五、用户管理（Users）

**日常操作**（界面已实测）：

| 任务 | 操作 |
|---|---|
| 查用户 | 顶部搜索框「按用户名、姓名或邮箱筛选」；可按状态/角色过滤 |
| 看用户概况 | 表格列：ID / 用户名 / 状态 / 额度 / 分组 / 角色 / 邀请信息（已邀请人数+返利收入） |
| 编辑用户 | 行尾铅笔图标打开抽屉：可改用户名、角色、显示名、**密码**、分组、额度、备注、管理权限 |
| 调额度 | 编辑用户 → 修改额度（充值补单、人工赠送场景） |
| 封禁/解封 | 编辑用户改状态；禁用后该用户立即无法调用 API 与登录控制台 |
| 删除用户 | 行尾「⋯」菜单 → 删除 → 确认（已实测删除测试账号，即时生效） |
| 提管理员 | 编辑用户 → 角色改为管理员/超管（**谨慎，仅超管可操作**） |

> 处理"充值未到账"工单时：先在 Users 页核对用户额度变动记录，再到其使用日志确认，最后人工补额度。

## 六、兑换码（Redemption Codes）

1. **批量生成**：右上角「**创建代码**」→ 填名称、USD 额度（面额）、过期时间、数量 → 生成（字段已实测）
2. **发放**：在列表中查看并复制码发给用户（售卖/活动/补偿场景）
3. **查询状态**：未使用 / 已使用 / 使用人 / 使用时间
4. **作废**：删除未使用的兑换码即时失效

> 兑换码面额创建后不可改，发错只能作废重发；导出文件含明文码，注意保管。

> 📌 **2026-08-17 已实测调整的生产配置**：「模型与路由 → 路由可靠性」中——跨渠道**重试次数 0→2**（此前不重试，单渠道故障用户直接报错）；**定期渠道测试已开启**（10 分钟全量，渠道卡片「上次测试」实时刷新）；**禁用阈值 5→60 秒**（见下方事故记录）；「监控与警报 → 模型性能指标」（延迟/成功率采集）保持开启。另：root 已在「个人资料 → 设置与偏好」开启「**接收上游模型更新通知**」（上游新模型上架会收到通知）。
>
> ⚠️ **事故记录与教训（2026-08-17）**：开启「定期渠道测试」后，存量的「禁用阈值 5 秒」对 LLM 推理类测试过严（该上游实测响应 2–5.6 秒），首次定时测试耗时 5.6s 超阈值 → 唯一渠道被自动禁用 → 全站 API 约 1 小时 503 + 游乐场无模型可选。处置：阈值调至 60 秒 + 手动启用渠道，复测两个测试周期稳定。**教训：开启自动测试前必须先核对禁用阈值与上游正常延迟的匹配性。**

> ⚠️ 每页改动后点右上角「**保存更改**」；支付网关（微信 Native / 支付宝当面付）的商户密钥改动后，**务必用小额真实订单验证回调**再放行。

平台部署有独立 observability 容器栈（与业务容器同在 feifei 服务器）：

| 组件 | 容器名 | 用途 |
|---|---|---|

## 十一、高频运营任务 SOP

### 11.1 接入一个新的上游模型供应商

1. 「渠道」→「创建渠道」→ 填上游地址和密钥
2. 配置该渠道支持的模型列表（必要时配模型映射）
3. 点卡片上的闪电图标「测试」确认连通
4. 「模型」页确认定价已覆盖新模型
5. 打开 `https://ai.yuxin.yun/pricing` 确认对外展示
6. 用普通用户 Key 实际调一次，到使用日志确认扣费正常

### 11.2 发放兑换码（活动/补偿）

1. 「兑换码」→「创建代码」→ 设置名称、USD 面额、过期时间、数量 → 生成
2. 在列表复制码，通过客服渠道发给用户
3. 用户在「钱包」页兑换；在兑换码列表可追踪使用情况

### 11.3 处理"调用报错"工单

1. 「用户」页搜到用户 → 确认未被封禁、有额度
2. 让用户提供报错时间与模型名 → 在使用日志中定位该次调用
3. 若是上游渠道故障：「渠道」页测试对应渠道 → 必要时临时禁用
4. 补偿：编辑用户调额度或发兑换码

### 11.4 发布全站公告

「系统设置 → 站点与品牌 → 系统公告」→ 编辑保存，用户登录即见。

## 十二、安全守则

1. 管理员账号一律开 2FA，不共用账号，谁操作谁负责
   - 🔴 **2026-08-17 实锤警告**：root 账号（lijianping，用户 ID 1）两步验证当前为「**已禁用**」状态（个人资料页实测），仅凭密码即可登录。请客户本人立即在「个人资料 → 两步验证 → 启用」扫码绑定（需客户手机操作，无法代办）

5. 改系统设置遵循"一次只改一处、改完即验证"

## 十三、FAQ

**Q：普通管理员和超管差在哪？**
A：超管（role=100）独占「系统信息」页（带 Root 标记）及高危操作（如角色变更）；日常运营用普通管理员即可，遵循最小权限。

**Q：改了系统设置没生效？**
A：先确认点了右上角「保存更改」；部分设置（如 SMTP）改动后需发一封测试邮件验证；仍异常查 `docker compose logs new-api`。

**Q：用户忘记密码怎么办？**
A：当前 SMTP 未配置，用户自助重置邮件发不出。管理员在「用户」页搜索该用户 → 编辑（铅笔图标）→ 直接在抽屉中设置新密码，线下告知用户并提醒其登录后自行修改。

**Q：如何临时关闭新用户注册？**
A：「系统设置 → 身份验证 → 基础认证」，关闭注册开关。当前注册策略决策记录见交付文档 `registration-policy-decision.md`。

**Q：告警 webhook 怎么接？**
A：服务器上编辑 `observability/alert-forwarder/config/webhooks.list`，写入接收地址即生效（基础设施 2026-08-15 已容器化落地）。

**Q：用户反映「登出」没反应？**
A：不是故障。「登出」有**二次确认弹窗**——点头像菜单的「登出」后需在弹窗中再确认一次才会真正退出（已实测会话完全失效）。

**Q：订阅套餐价格好像不对？**
A：2026-08-17 实测钱包页显示「基础套餐 $99.00 / 有效期 1 个月 / 总额度 $15」——价格 $99 高于包含额度 $15，疑似配置错误，请到「订阅」页核对套餐额度配置。
