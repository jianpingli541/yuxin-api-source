## 一、这个平台是什么

豫鑫 API 网关是一个 **AI 模型统一接入平台**。您只需要一个账号、一个 API Key，就可以通过统一的 OpenAI 兼容接口调用平台上的多种大模型，无需分别去各家模型厂商注册和付费。

平台特点：

- **一个 Key 调多个模型**：统一接口，切换模型只需改一个参数
- **按量计费**：用多少扣多少，余额实时可查
- **多语言界面**：简体中文 / 繁体中文 / English / Français / Русский / 日本語 / Tiếng Việt（右上角可切换）
- **在线试用**：内置 Playground 和聊天界面，不写代码也能先体验模型效果

## 二、快速上手：5 步完成第一次调用

| 步骤 | 操作 | 位置 |

## 三、注册、登录与账户安全

### 3.1 注册

1. 打开 https://ai.yuxin.yun，点击「注册」
2. 填写用户名，按页面提示设置密码（8–20 位），勾选同意用户协议
3. 提交后自动登录并进入控制台

> 注册只需用户名 + 密码，无需邮箱。建议注册后到「个人资料」补绑邮箱（用于找回密码）。

### 3.2 登录与找回密码

- 登录入口：首页右上角「登录」
- 忘记密码：登录页有「忘记密码」入口，通过邮箱接收重置邮件。**注意：平台当前未配置邮件服务，重置邮件无法发出**——忘记密码请联系平台运营方人工重置
- 第三方登录（GitHub / Google 等）：当前未开通；如后续开通，登录页会显示对应按钮

### 3.3 账户安全（强烈建议设置）

登录后进入左侧菜单「个人资料」，可以设置：

| 功能 | 位置（「个人资料」页内） | 说明 |
|---|---|---|
| **两步验证（2FA）** | 「两步验证」卡片 →「启用」 | 绑定 Authenticator（如 Google/微软 Authenticator），登录时除密码外还需 6 位动态码。**强烈建议开启** |
| **通行密钥（Passkey）** | 「Passkey 登录」卡片 →「启用 Passkey」 | 用指纹 / 面容 / 设备 PIN 登录，设备支持可开启 |
| **登录会话管理** | 「登录会话」卡片 | 查看所有已登录设备（IP/时间），可单个「登出」或「退出其他会话」。**建议定期查看** |
| **绑定邮箱 / 修改密码** | 「设置 → 账户绑定」 | 绑定邮箱是找回密码的前提 |

> ⚠️ API Key 等同于您的账户余额钥匙，**不要写死在公开代码仓库里**。怀疑泄露时立即到「API Keys」页面删除重建（删除即时生效）。

## 四、控制台各页面说明

登录后左侧菜单分为三组：聊天、常规、个人。

### 4.1 聊天

| 页面 | 用途 |
|---|---|
| **游乐场** | 在线试模型：先选模型（输入框右下角选择器）、输入内容直接对话，适合接入前评估效果。已实测真实对话 |
| **聊天** | 预置的聊天与客户端快捷入口（含 Cherry Studio、LobeChat、DeepChat、OpenCat 等客户端一键导入配置） |

### 4.2 常规

| 页面 | 用途 |
|---|---|
| **概览** | 账户数据总览：余额、用量趋势、新手引导、API 信息、平台公告 |
| **数据看板** | 按模型维度的用量统计图表 |
| **API 密钥** | 管理您的密钥（详见下方） |
| **使用日志** | 每一次 API 调用的明细：时间、模型、输入/输出 token 数、本次扣费 |
| **任务日志** | 异步任务记录（绘图等耗时任务的状态和结果） |

**API 密钥页操作要点**（表格列：名称 / 状态 / API 密钥 / 额度 / 分组 / 模型 / IP 限制 / 操作）：

- **新建**：点「创建 API 密钥」，可设置名称、额度上限（留空 = 不限）、过期时间（留空 = 永久）、允许调用的模型范围、可用分组、IP 白名单
- **复制 Key**：列表中 Key 以 `sk-****` 掩码显示，点击密钥右侧的**复制图标**即可复制完整 Key（已实测）
- **分组**：不同分组对应不同计费倍率/可用模型（由管理员配置），按需要在 Key 上选择
- **启停/删除**：「操作」列可禁用或删除，删除即时生效

### 4.3 个人

| 页面 | 用途 |
|---|---|
| **钱包** | 余额、充值、订阅套餐、推荐奖励、订单历史（详见下一章） |
| **个人资料** | 账户绑定（邮箱）、语言偏好、安全（2FA/Passkey）、登录会话、侧边栏显示个性化 |

## 五、钱包：充值、订阅与奖励

进入左侧菜单「钱包」，包含以下区块：

### 5.1 余额充值（按量付费）

1. 在「添加资金」卡片选择金额：预设档位 10 / 20 / 50 / 100 / 200 / 500（美元额度），或输入自定义金额；按汇率 7.3 折算人民币支付（如 $10 → ¥73）
2. 选择付款方式：**微信支付**（扫码）/ **支付宝**（扫码）/ 自定义通道（页面显示「自定义1」，最低 ¥50）
3. 手机扫码完成付款，额度一般即时到账
4. 到账后页面顶部「当前余额」更新；充值记录可点「订单历史」查询

### 5.2 订阅套餐

「订阅套餐」卡片展示当前在售套餐（当前为「基础套餐」$99/月，以页面实际展示为准）。购买后在有效期内按套餐规则计费；可设置「优先钱包」或「优先订阅」。

### 5.3 推荐奖励

「推荐奖励」卡片提供您的专属邀请链接。新用户通过该链接注册并消费后，您可获得一定比例返利额度。

### 5.4 兑换码

如果您拿到了兑换码（卡密），在「钱包」页**底部「有兑换码吗？」输入框**输入码，点「兑换额度」即可充入（已实测：兑换后 toast 提示「兑换成功！已添加：$X」，余额即时更新）。

## 六、API 调用方法

平台提供 **OpenAI 兼容接口**，几乎所有支持 OpenAI 的客户端/框架都能直接接入，只需改两个地方：

| 配置项 | 值 |
|---|---|
| Base URL | `https://ai.yuxin.yun`（部分客户端要求填 `https://ai.yuxin.yun/v1`） |
| API Key | 您在「API Keys」页面创建的 `sk-...` 密钥 |

### 6.1 curl 示例

```bash
curl https://ai.yuxin.yun/v1/chat/completions \
  -H "Authorization: Bearer sk-你的Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MiniMax-M2.5",
    "messages": [{"role": "user", "content": "你好"}]
  }'
```

### 6.2 Python（openai 官方 SDK）示例

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://ai.yuxin.yun/v1",
    api_key="sk-你的Key",
)

resp = client.chat.completions.create(
    model="MiniMax-M2.5",
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)
```

> **路由透明化**：每次调用的响应头会带 `X-Yuxin-Model`，标明该请求实际生效的上游模型（发生模型映射或故障转移时以它为准）。

### 6.3 查看可用模型与价格

- 模型清单与单价：无需登录，打开 https://ai.yuxin.yun/pricing （页面顶部导航中显示为「模型广场 / Model Square」）
- 代码内查询：`GET https://ai.yuxin.yun/v1/models`（带 Key）
- 当前平台提供 10 个模型（2026-08-17 实测）：MiniMax-M2.5、glm-5.2、glm-5.1、qwen3.5-plus、qwen3.6-plus、qwen3.6-flash、qwen3.7-plus、qwen3.7-max、deepseek-v4-pro、deepseek-v4-flash

### 6.4 常见报错（前两条为 2026-08-17 真实调用实测）

| 错误 | 含义 | 处理 |
|---|---|---|
| 401 `无效的令牌` | Key 无效或已删除 | 检查 Key 是否复制完整；必要时重建 |
| 403 `用户额度不足` | 账户额度不够（源码实证） | 去「钱包」充值 |
| 429 | 请求过快触发限流 | 降低并发后重试 |
| 503 `分组 default 下模型 X 无可用渠道` | 模型名拼写错误或该模型未对您的分组开放 | 对照 `/v1/models` 返回的模型名；确认无误仍报错请联系运营方 |

> **注意**：直接用 Python 裸 `urllib`（默认 UA）调用会被 Cloudflare 拦截（403 / error code: 1010）。请使用 openai 官方 SDK、requests、httpx 或 curl——均已实测可正常访问。

## 七、计费规则说明

- **按 token 计费**：每次调用按 输入 token 数 × 输入单价 + 输出 token 数 × 输出单价 扣费，各模型单价见 Pricing 页
- **分组倍率**：不同用户分组/Key 分组可能对应不同折扣倍率，实际扣费 = 标准价 × 倍率
- **订阅与按量并存**：订阅套餐在有效期内优先按套餐规则；套餐外或到期后按量扣余额
- **每一笔都能查**：所有扣费在「使用日志」逐条可查（模型、token 数、金额），对账有据

## 八、常见问题 FAQ

**Q：注册后必须充值才能用吗？**
A：是的。新账号余额 $0、无免费额度（实测）；Pricing（模型广场）/ Rankings 等公开页面无需登录即可查看；正式 API 调用前请先充值或用兑换码。

**Q：API Key 找不到了 / 怀疑泄露了？**
A：Key 完整值只在创建时显示一次，无法找回，只能到「API Keys」页删除后新建。怀疑泄露请**立即删除**。

**Q：充值后没到账？**
A：扫码支付一般即时到账。若超过 10 分钟未到账，保留支付截图联系平台运营方处理。

**Q：怎么把界面切成中文/英文？**
A：页面右上角有语言切换器，共 7 种语言；也可在「个人资料 → 语言偏好」中固定。

**Q：支持哪些客户端？**
A：任何支持自定义 OpenAI Base URL 的客户端都可以（如 NextChat、LobeChat、沉浸式翻译、Cherry Studio 等），填入 `https://ai.yuxin.yun/v1` 和您的 Key 即可。侧边栏「聊天」菜单内置了 Cherry Studio、LobeChat、DeepChat、OpenCat 等客户端的一键导入配置。

**Q：想开发票 / 对公付款？**
A：请联系平台运营方（豫鑫）商务渠道。
